Font license provenance
=======================

Full upstream OFL files retrieved on 2026-10-01:

- Lato-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/lato/OFL.txt
- Noto-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssymbols2/OFL.txt

The packager pins these exact bytes. Staging retains the pinned font binaries'
embedded copyright, author, license and Reserved Font Name notices, then appends
the full upstream license including all conditions and disclaimer. The upstream
Lato family license is supplemental to the LatoLatin binaries' embedded notices;
it does not replace those notices. No font binary is modified.
